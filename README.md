# SQL Data Warehouse Project

## Project Overview

This project focuses on building a **Data Warehouse using SQL Server** by integrating sales data from ERP and CRM source systems. It demonstrates the process of collecting, cleaning, transforming, and organizing data for analysis and reporting.

The project follows the **Medallion Architecture** with three layers:

- **Bronze Layer** – Stores raw data from source systems.
- **Silver Layer** – Contains cleaned and transformed data.
- **Gold Layer** – Contains business-ready data organized into Fact and Dimension tables.

## Project Workflow

1. Load raw data from ERP and CRM source systems into the Bronze Layer.
2. Clean and transform data in the Silver Layer.
3. Integrate data from multiple sources.
4. Create Fact and Dimension tables in the Gold Layer.
5. Build a Star Schema for data analysis and reporting.

## Analytics

The data warehouse can be used to analyze:

- Customer Behavior
- Product Performance
- Sales Trends
